# ☕ Starbucks Coffee Sales Dashboard – Excel Project
## 📌 Project Overview

The Starbucks Coffee Sales Dashboard is an interactive Excel-based business intelligence project designed to analyze coffee sales performance across different time periods, coffee categories, weekdays, payment methods, and customer purchasing trends.

This project transforms raw transactional sales data into meaningful visual insights using Excel dashboards, charts, pivot tables, slicers, and KPI cards.

The dashboard helps in:

Monitoring total sales and order performance
Identifying top-selling coffee products
Understanding customer buying behavior
Analyzing monthly, quarterly, and yearly sales trends
Comparing sales across weekdays and time of day

## 🎯 Objectives of the Project
* Analyze Starbucks coffee sales data effectively
* Create an interactive Excel dashboard
* Identify customer purchase patterns
* Track monthly and yearly sales trends
* Compare product performance
* Improve decision-making using data visualization


## 🛠 Tools & Technologies Used
* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Conditional Formatting
* KPI Cards
* Data Cleaning & Transformation
* Dashboard Design & Formatting

## 📊 Dashboard Features

### 1️⃣ Yearly Sales Analysis Dashboard

The **Yearly Sales Analysis Dashboard** provides insights into overall Starbucks sales performance throughout the year. It includes analysis of total sales, total orders, quarter-wise sales distribution, coffee-wise average sales, payment mode analysis, and time-of-day sales trends.

Key highlights include:

* 💰 **Total Sales:** `$115,431.58`
* 🛒 **Total Orders:** `3636`
* 📈 Quarter-wise sales analysis
* ☕ Coffee category comparison
* 💳 Cash vs Card payment analysis

---

### 2️⃣ Monthly Sales Analysis Dashboard

The **Monthly Sales Analysis Dashboard** focuses on monthly and weekday-wise sales performance. It helps analyze monthly trends, sales contribution by time of day, best-performing weekdays, and top-selling coffee products.

Key insights include:

* 📅 **Best Performing Day:** `Monday`
* ☕ **Top Selling Coffee:** `Latte`
* 📊 Monthly sales trend analysis
* 🕒 Morning, Afternoon & Night sales comparison

## 🔍 Insights Derived
* Latte generated the highest sales among coffee categories.
* Card payments were used more frequently than cash payments.
* Afternoon sales contributed significantly to total revenue.
* Monday showed the strongest overall sales performance.
* Sales fluctuated across quarters with visible seasonal trends.
