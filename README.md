# ☕ Starbucks Coffee Sales Dashboard – Excel Project
## 📌 Project Overview

The Starbucks Coffee Sales Dashboard is an interactive Excel-based business intelligence project designed to analyze coffee sales performance across different time periods, coffee categories, weekdays, payment methods, and customer purchasing trends.

This project transforms raw transactional sales data into meaningful visual insights using Excel dashboards, charts, pivot tables, slicers, and KPI cards.

The dashboard helps in:

Monitoring total sales and order performance
Identifying top-selling coffee products
Understanding customer buying behavior
Analyzing monthly, quarterly, and yearly sales trends
Comparing sales across weekdays and time of day

## 🎯 Objectives of the Project
* Analyze Starbucks coffee sales data effectively
* Create an interactive Excel dashboard
* Identify customer purchase patterns
* Track monthly and yearly sales trends
* Compare product performance
* Improve decision-making using data visualization


## 🛠 Tools & Technologies Used
* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Conditional Formatting
* KPI Cards
* Data Cleaning & Transformation
* Dashboard Design & Formatting
